## How it works

The filter tracks two numbers: the robot's position and its velocity. It never sees the velocity directly. It only gets a position reading from the sensor every 0.1 seconds, and that reading is noisy.

Each step has two parts.

1. **Predict.** Use physics to guess the next state. The model says the new position is the old position plus velocity times 0.1 s, and the velocity stays the same. The filter also grows its uncertainty a little, because the real robot can do things the model does not expect.
2. **Update.** Compare the prediction with the new sensor reading. The Kalman gain decides how much to trust each one. When the filter is unsure of its prediction, it leans on the sensor. When the sensor is noisy, it leans on the prediction.

| Matrix | Value | What it means |
|---|---|---|
| `A` | `[1 0.1; 0 1]` | Physics: position moves by velocity times 0.1 s |
| `H` | `[1 0]` | The sensor measures position only |
| `Q` | `[0.1 0; 0 0.1]` | Process noise: how much the robot can surprise the model |
| `R` | `10` | Sensor noise variance (a standard deviation of about 3.2 m) |
| `P` | `[1 0; 0 1]` | Starting uncertainty |

This is the loop from my MATLAB script:

```matlab
for i = 1:length(time)
    % Predict
    x_pred = A * x;
    P_pred = A * P * A' + Q;

    % Update
    K = P_pred * H' / (H * P_pred * H' + R);
    x = x_pred + K * (noisy_data(i) - H * x_pred);
    P = (eye(2) - K * H) * P_pred;

    filtered_estimate(i) = x(1);
end
```

To test it, the script simulates a robot that starts at rest and speeds up at 1 m/s² for 10 seconds, so its true position is 0.5t². The sensor readings are that true position plus random Gaussian noise with a variance of 10.

## What went wrong and what I optimized

The filter's estimate runs a little behind the true position. The model assumes the velocity stays the same, but the simulated robot keeps speeding up, so the filter is always catching up. In the last 3 seconds of the run below, the estimate is about 1.1 m behind on average. Across 200 runs it is about 1.0 m behind.
